# Ethernet and clocking RTL

The parts of the VC707 ethmin design this repository builds on, copied here
so `fpga/vc707-ethmin` needs no second checkout: the Vivado build, the open
(yosys/nextpnr) build and both simulations read them from this directory.

Only the tools stay external -- yosys, nextpnr, prjxray's database and the
Python environment come from xc7-bitstream-tools (`$XC7BT`), which is what
`open_build.sh` points at.

| file | from | licence |
| --- | --- | --- |
| `simpleuart.v` | PicoSoC (Claire Xenia Wolf) | ISC |
| `eth_mac_1g.sv`, `axis_gmii_rx.sv`, `axis_gmii_tx.sv`, `rgmii_lfsr.sv` | verilog-ethernet (Alex Forencich) | MIT |
| `eth_lutram_fifo.sv`, `eth_stream_dma.sv`, `eth_gmii_retime256.sv`, `eth_pkt_buf256.sv`, `sgmii_soc_liteeth.sv` | vc707-openflow-demos' ethmin | as marked in each file |
| `liteeth_sgmii_phy.v` | generated by LiteEth (the SGMII PCS/PMA on a GTX) | BSD-2-Clause |
| `clkgen_vc707.sv` | lowRISC | Apache-2.0 |

Every file keeps its original header.  They came from
xc7-bitstream-tools' `examples/vc707-ethmin/rtl`, which in turn documents
their provenance in its own README.

One change from the originals: `clkgen_vc707.sv` takes a `SYS_DIV`
parameter, so a design can ask for a clock other than 25 MHz (this one runs
at 50).  The default leaves every other user of the file unchanged.

Updating from upstream is a copy; the diff is worth reading first, since a
change to `eth_stream_dma.sv`'s memory interface or to `clkgen_vc707.sv`'s
outputs lands in `fpga/vc707-ethmin/ethmin_vm_core.v`.
